5. Use an owner-approved PayPal activation **only after** G1–G4 pass. Do not substitute payment instructions or external personal payment handles.
6. Log first-sale conversion only from valid provider events **plus** customer report delivery; separately measure refunds, failures, fraud disputes and actual provider fees.
