## Release boundaries

V2.1 preserves the deterministic architecture:

- no generative AI
- no embeddings
- no fuzzy matching
- no opaque scoring or ATS prediction
- raw lexical compatibility remains available separately
- relevant/curated findings remain explicit and reviewable
- document processing remains request-scoped and non-persistent by application design

## Follow-up / backlog

The following are not V2.1 release blockers and should be treated as separate future work if activated:

- optional `v2.1.0` semantic-version tag / GitHub Release
- dependency upgrades from Dependabot, especially major framework/runtime changes
- PyMuPDF `fitz` deprecation cleanup when a maintained migration path is adopted

V2.1 should not be reopened unless a new regression, provider failure, or explicitly approved follow-up scope is identified.
