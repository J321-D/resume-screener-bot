# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this repository. Do not open a public issue containing exploit details before a fix can be assessed.

Never attach a real résumé, job description, API credential, environment value, or other personal information to a report. Use minimal synthetic text and describe the affected boundary instead.

## Scope

Security reports should concern the current public Version 2 application and supported repository code. The project does not promise a response-time SLA. Product feedback and non-sensitive defects can use the normal issue tracker.
